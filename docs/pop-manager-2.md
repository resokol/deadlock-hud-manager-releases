# Pop Manager 2.0

Pop Manager готовит камеры на компьютере vMix. Два средства переключения остаются в существующем тракте студии. Обсервер выбирает оригинал с эфирным кадрированием. Повторщик со Stream Deck выбирает нативную копию с полным кадром в своём Mix. vMix принимает команды Companion напрямую. Закрытие Pop Manager останавливает подготовку и мониторинг камер.

## Первоначальная настройка

1. Сохраните пресет vMix. Подготовьте **12 Web Browser на входах 1–12** и включите **Settings → Web Controller**. Запишите IP и порт. Для каждой камеры настройте своё кадрирование у оригинала.
2. Запустите **START-POV.cmd**. Укажите адрес vMix. В настройке пула проверьте 12 пар. Если копий ещё нет, используйте явную команду создания недостающих Virtual Input. Для каждой пары нужен один оригинал и одна нативная копия, всего 24 входа. Если vMix скрывает ссылку на родителя, укажите существующую копию вручную, сверив её в пресете. Повторно сохраните пресет после настройки. [Команды vMix 29](https://www.vmix.com/help29/ShortcutFunctionReference.html) · [Нативная виртуальная копия](https://www.vmix.com/help29/InputSettingsGeneral.html)
3. У каждой копии откройте **Input Settings → Position** и проверьте полный кадр. В **General** выберите исходные пропорции, выключите Mirror, проверьте поворот. Синхронизация задаёт поддерживаемые Pan X/Y, Zoom и Crop на копиях. Web API может скрывать часть трансформаций.
4. Настройте **Replay Mix**, например Mix 2. В **Settings → Outputs** выберите вход этого Mix источником **Output 2**. В настройках **External Output → External 2** выберите устройство и физический порт, разрешение и частоту. Запустите внешний выход. В vMix 29 несколько External доступны в редакциях 4K и выше. [Назначение Output 2](https://www.vmix.com/help29/SettingsOutputs.html) · [External Output](https://www.vmix.com/help29/ExternalOutput1.html)
5. На вкладке **Match** выберите Panorama и вставьте сетевой URL матча из HUD Manager на ПК обсерва. На ПК обсерва должны быть включены данные Panorama и доступ по локальной сети. Альтернативно выберите SourceTV и введите Match ID. Когда доступен только состав и линии, сравните список с портретами в игре и подтвердите вручную. Источник истины для раскладки по клавишам — порядок портретов слева направо.

## Кнопки Stream Deck без промежуточного сервера

В **Companion → Connections** откройте своё подключение **StudioCoast: vMix**. Включите **Input Variables by Number**. В примерах метка подключения — `vmix`. Если у подключения другая метка, выберите соответствующую переменную через список Companion.

| Кнопка | Текст в обычном поле Button text | Действие на нажатие | Input | Mix |
|---|---|---|---|---|
| 1 | `$(vmix:input_1_name)` | Transition - Send Input to Program | `13` | 2 |
| 7 | `$(vmix:input_7_name)` | Transition - Send Input to Program | `19` | 2 |
| 12 | `$(vmix:input_12_name)` | Transition - Send Input to Program | `24` | 2 |

В **Buttons → Style → Text** вставьте переменную оригинала, чтобы показывать только ник. Для остальных кнопок *N* замените число в тексте на *N* и в поле **Input** действия поставьте числом *N + 12*. В списке **Mix** выберите номер вашего выделенного Mix. Если кнопку прежде настраивали через GUID или имя пользователя, замените значение Input числом. Число выбирает новую камеру, занявшую эту позицию после смены сторон. На повторщике достаточно Companion и маршрута External 2. [Действие Program в модуле 5.0.5](https://github.com/bitfocus/companion-module-studiocoast-vmix/blob/v5.0.5/src/actions/transitionActions.ts) · [Переменные по номеру входа](https://github.com/bitfocus/companion-module-studiocoast-vmix/blob/v5.0.5/src/variables/inputVariables.ts)

## Матч

1. **До игры** откройте вкладку **VDO Ninja**, вставьте ссылку директора или со-режиссёра и нажмите **Подключиться**. При необходимости завершите вход в сессии менеджера. Дождитесь подтверждения комнаты и проверьте статусы гостей и входов. Игрокам нужен уникальный VDO Label, совпадающий с игровым ником. Пустой ответ при первом подключении возможен до авторизации. В таком случае дождитесь первого видимого гостя.
2. **После появления портретов** откройте **Match**. Проверьте ник на каждой из 12 позиций. При пустых или одинаковых VDO Label откройте **VDO Ninja → Имена гостей…** и укажите игровой ник нужному Stream ID. Если игровой ник отличается от имени камеры, откройте **Match → Сопоставить игроков с камерами…** и выберите оригинал. Для игрока с Account ID менеджер сохраняет назначение по этому ID. Нажмите **Синхронизировать с матчем**. Дождитесь проверки обоих банков по ответу vMix. Позиция 1 соответствует клавише `1`, позиция 10 — `0`, 11 — `-`, 12 — `=`. Когда стороны меняются, сверьте новый порядок и повторите синхронизацию в удобный момент.
3. **Во время игры** держите мониторинг включённым для автоматической обработки потери или возвращения камеры. Отключение участника сохраняет его позицию и ник. Пропажа связи со всей комнатой приостанавливает выводы о состоянии камер. Свободный вход в следующем матче можно использовать для замены игрока. Сверяйте конфликты ников до отправки в vMix.
4. **Следующий матч** использует те же GUID. Если до матча меняется состав и нужно освободить закреплённые позиции, после окончания предыдущей карты выберите **VDO Ninja → Настройка пула vMix → Начать подготовку нового состава**. Если меняется только игровой порядок, достаточно новой синхронизации. При смене пресета или ручном перемещении проверьте пары. Если во время перестановки пропала связь, прочитайте статус восстановления, дождитесь свежего каталога и сверьте порядок до повторной команды. Во время физической перестановки vMix обрабатывает слоты последовательно. Кнопка, нажатая в этот короткий интервал, обращается к текущему номеру входа.

## Управление и восстановление

На вкладках **Live** и **Replay** флаги «Управлять … из Pop Manager» независимо разрешают ручные команды менеджера. Для обычных кнопок Stream Deck, настроенных напрямую на vMix, оба флага можно выключить. Мониторинг имеет собственный переключатель на вкладке **VDO Ninja**. Автослежение Live включайте только если хотите, чтобы Pop Manager отправлял исходную камеру наблюдаемого игрока в эфирный Mix. Укажите разные Mix для Live и Replay.

Если во время сортировки прервалась связь, сохраните выбранные источники в vMix и прочитайте состояние на вкладке **Match**. Восстановление сверяет пресет, GUID, имена, отображаемую геометрию и текущие Program по журналу. Если оператор за это время изменил пресет, откройте «Журнал восстановления…» и сверьте прежнюю конфигурацию. Для скрытых в XML значений используйте сохранённый перед настройкой пресет. Загружайте полный пресет в подходящий для эфира момент.

После ручной замены URL в том же пресете vMix может не показать новый адрес в XML. Чтобы заново применить ссылки комнаты, откройте **VDO Ninja → Настройка пула vMix → Повторно загрузить страницы камер…**. Это явная перезагрузка активных браузеров. При исчезновении камер из всей комнаты менеджер ждёт достоверного обновления. Если состояние одиночного потока помечено как неизвестное, проверьте камеру у гостя. Кнопка «Показать вход VDO.Ninja» открывает текущую сессию для авторизации. После перезапуска менеджер проверяет сохранённый порядок по свежему каталогу vMix до возобновления команд. При зависшем счётчике кадров и отсутствии достоверного сообщения об отключении статус становится неизвестным. Перед выключением такого входа проверьте источник.

## Проверка прозрачности по двум точкам

1. В тестовом пресете выберите разные камеры в Live и Replay. Используйте камеру с заметным кадрированием оригинала. Сравните все края изображения виртуальной копии с исходной веб-камерой. Измените Pan у оригинала и проверьте полный кадр у копии.
2. **Внутри vMix** наложите проверяемую камеру на контрастную тестовую подложку в контрольной композиции. Выключите видео гостя, оставив его в комнате. После подтверждения потери видео через место камеры должна быть видна подложка. Проверьте отдельно оригинал и копию. Включите видео и сверьте ник, GUID, кадрирование и прежнюю непрозрачность. Если доступна только подстановка пустой страницы, восстановление включает время соединения WebRTC.
3. **На физическом приёмнике External 2** выберите Replay Mix. Для передачи прозрачности настройте поддерживаемый устройством формат с альфа-каналом либо тракт Fill/Key с соответствующей настройкой приёмника. Подложите цвет на стороне приёмника и повторите отключение камеры. Полностью прозрачный вход в одиночном Program на чёрном фоне выглядит чёрным. Видимый чёрный прямоугольник поверх контрольного цвета на приёмнике означает, что переданный сигнал не дал прозрачности в этом тракте. Зафиксируйте модель видеокарты вывода, формат и выбранный режим keying. [Настройки внешнего устройства](https://www.vmix.com/help29/ExternalOutput1.html) · [Key и Fill в vMix](https://www.vmix.com/help29/KeyFill.html)
4. Дайте оператору повторов нажать кнопки 1, 7 и 12, затем закройте Pop Manager и повторите. В выделенный Mix должны попадать 13, 19 и 24. Убедитесь, что Live сохраняет своего игрока. Проведите такую проверку также после смены сторон.
