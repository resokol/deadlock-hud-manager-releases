# Pop Manager 2.4

Распакуйте ZIP в отдельную папку, закройте предыдущую копию Pop Manager и запустите **START-POV.cmd**. Для первого запуска нужен интернет. Этот архив предназначен для ПК с POV Manager. На ПК наблюдателя продолжайте использовать установленный HUD Manager.

## Получить состав

- **По Match ID · SourceTV.** Введите ID и нажмите **Подключиться**. После получения 12 игроков с данными о линиях таблица заполнится автоматически. SourceTV группирует обе команды по линиям. Порядок двух игроков внутри линии определяется порядком данных источника и может отличаться от портретов в игре.
- **Panorama · HUD Manager.** На ПК наблюдателя в HUD Manager выберите **Только JSON** или **Полный HUD**, затем нажмите вверху **Копировать URL для Pop Manager**. Если у ПК несколько сетевых карт, выберите нужный адрес рядом с кнопкой. Вставьте полный URL в Pop Manager и нажмите **Подключиться**. Ссылка содержит IP, порт и ключ. Менеджер запоминает её для следующих подключений. Когда HUD передаст все портреты, таблица покажет их порядок слева направо.

## Применить к vMix

Укажите IP компьютера с vMix и порт Web Controller (обычно 8088). В поле **Входы vMix** доступны два режима.

- **Стандартные входы 1–24** использует оригиналы Web Browser на местах 1–12 и копии на местах 13–24. При применении менеджер создаёт недостающие Virtual Input и выравнивает порядок копий.
- **Выбрать входы из vMix** загружает существующие входы. Для каждой игровой позиции выберите номер и название оригинала и его нативной виртуальной копии в таблице. Входы можно выбирать в любом порядке. Когда vMix сообщает родительский GUID единственной копии, менеджер подставляет её автоматически. Если vMix скрывает связь, выберите копию после сверки в пресете. Для повторного чтения каталога нажмите **Обновить список**. Полный выбор сохраняется по GUID для этого адреса, порта и пресета.

Нажмите **Применить к vMix** и дождитесь **24/24**. Оригинал получает игровой ник, а копия — название «Ник - Virtual» и настройки полного кадра. В режиме выбора менеджер работает с указанными входами на их текущих местах. Для Stream Deck нумерация в hud_slots по-прежнему соответствует позициям игроков 1–12.

## Следующая карта

Для SourceTV введите ID новой карты. Для Panorama достаточно одного подключения к HUD Manager. При смене карты или сторон таблица и JSON для Companion обновляются после получения свежих 12 портретов. При смене карты Pop Manager показывает новый ID сразу после его получения, даже пока портреты загружаются. Если ID ещё не появился, позиции уже доступны, а поле matchId временно содержит null. При потере данных таблица и hud_slots очищаются. После появления нового состава нажмите **Применить к vMix** для обновления входов. Запись в vMix запускается кнопкой применения.

## Bitfocus Companion

Нажмите **Копировать URL для Companion** в Pop Manager. В Companion используйте этот URL для периодического HTTP GET и сохраняйте ответ как JSON-объект в custom-переменную deadlock_match. Если компьютер имеет несколько сетевых интерфейсов, откройте **Настройки сети** и выберите интерфейс, доступный ПК с Companion. Адрес, порт и токен от версии 2.2.2 используются повторно, если выбранный интерфейс доступен.

В поле выражения текста кнопки 12 вставьте:

```text
$(custom:deadlock_match)["hud_slots"]["12"]
```

Для остальных кнопок подставьте номер позиции от 1 до 11. API публикует тот же состав, который виден в таблице, ещё до записи названий в vMix.
